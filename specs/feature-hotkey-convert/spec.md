# Feature Spec: feature-hotkey-convert

## 1) Problem
Користувач часто набирає слово або коротку фразу в неправильній розкладці (наприклад, EN замість UA) і змушений вручну стирати та друкувати заново. Потрібен швидкий ручний спосіб виправити вже набраний текст через hotkey без автоздогадок.

## 2) Scope
In:
- Ручне перетворення останнього слова за hotkey.
- Ручне перетворення виділеного тексту за hotkey.
- Підтримка двох мап розкладок у MVP: `UA <-> EN`.
- Повернення фокусу в активне поле після заміни.

Out:
- Автоматичне визначення "не тієї" розкладки під час набору.
- Автозаміни скорочень (окрема фіча).
- Налаштування UI (тимчасово через конфіг-файл).

## 3) Acceptance Criteria
1. [ ] Натискання hotkey на останньому слові перетворює це слово `UA <-> EN` без зміни сусіднього тексту.
2. [ ] Натискання hotkey при наявному виділенні перетворює тільки виділений фрагмент.
3. [ ] Для рядків довжиною до 200 символів перетворення виконується не довше 100 мс у типовому локальному сценарії.
4. [ ] Якщо перетворення неможливе (порожній текст, нема активного editable-поля), застосунок не падає і логгує подію.
5. [ ] Повторне натискання hotkey на щойно перетвореному фрагменті повертає оригінальний текст (reversible mapping для підтриманих символів).
6. [ ] Пунктуація та пробіли зберігаються без модифікацій.

## 4) Constraints
- Платформа: Windows (MVP).
- Реалізація як локальний desktop/tray інструмент.
- Не використовувати мережеві сервіси.
- Гарячі клавіші мають бути глобальними і не блокувати системні комбінації за замовчуванням.

## 5) Edge Cases
- Змішаний текст: `ghbdtn, світ!` (частина EN-символів, частина UA).
- Текст з цифрами: `ghbdtn123`.
- Виділення з переходом рядка.
- Подвійні пробіли або пробіл перед пунктуацією.
- Поле, яке блокує synthetic input.
- Активне вікно змінилося між читанням і вставкою.

## 6) Risks
- Risk: Конфлікт hotkey з іншими програмами.
  - Severity: med
  - Mitigation: configurable hotkey + fallback комбінація.
- Risk: Некоректна інжекція тексту у специфічних застосунках.
  - Severity: high
  - Mitigation: багаторівневий injector (SendInput -> clipboard fallback), явне логування помилок.
- Risk: Неповна таблиця відповідностей символів.
  - Severity: med
  - Mitigation: unit-тести на mapping table + regression набір кейсів.
