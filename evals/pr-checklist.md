# PR Eval Checklist

## Process
- [ ] Spec exists and is approved.
- [ ] Plan exists and is approved.
- [ ] Tasks are up to date.
- [ ] Verify report is completed.

## Quality
- [ ] Lint passed.
- [ ] Tests passed.
- [ ] No blocker defects.
- [ ] Rollback plan documented.

## Review
- [ ] Reviewer comments resolved.
- [ ] Risks are explicit and accepted.
- [ ] Scope matches approved spec.
