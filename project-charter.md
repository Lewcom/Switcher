# Project Charter

## 1) North Star
Створити легкий локальний Windows-інструмент для:
- виправлення вже набраного слова/фрази в іншій розкладці;
- гарячих клавіш для ручного перемикання/перетворення тексту;
- автозамін (скорочення -> повний текст).

## 2) Problem Statement
Користувачі регулярно друкують "не тією" розкладкою та витрачають час на ручне виправлення тексту. Цей проєкт має прибрати ці мікровтрати часу без складного інтерфейсу та без хмарної залежності.

## 3) Product Goals
- Швидке виправлення останнього слова/виділеного фрагмента через hotkey.
- Надійні автозаміни за локальним словником.
- Проста конфігурація та передбачувана поведінка.

## 4) Success Metrics
- Conversion accuracy (ручні сценарії): >= 98% коректних перетворень.
- Hotkey latency: <= 100 ms у типовому випадку.
- Crash-free sessions: >= 99.5% локальних сесій.
- False positives автозамін: <= 1% у smoke-наборі.

## 5) Non-Goals (Out of Scope)
- Хмарна синхронізація налаштувань.
- NLP/AI-корекція тексту.
- Підтримка macOS/Linux у MVP.
- Плагінна екосистема у першій версії.

## 6) Constraints
- Працюємо на Windows (MVP).
- Пріоритет стабільності над кількістю фіч.
- Кожна фіча проходить spec-first + quality gates.

## 7) Delivery Principles
- Spec -> Plan -> Tasks -> Implementation -> Verify -> Review -> Merge.
- Маленькі PR: один логічний інкремент.
- Кожне рішення має rollback-план.
