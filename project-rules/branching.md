# Branching

- Main branch: `main`
- Feature branch naming: `codex/feature-<slug>`
- Один branch = одна фіча або підфіча.
- Часті невеликі коміти з зрозумілими повідомленнями.

## Commit Message Template
`<type>: <short-summary>`

Приклади:
- `feat: add manual layout convert hotkey handler`
- `test: add converter edge cases for mixed symbols`
- `docs: define acceptance criteria for auto-replace`
